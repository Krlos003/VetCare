# 💻 Instrucciones de Uso

¡Bienvenido a las instrucciones de uso de **VetCare**! 🐾

En este documento encontrarás los requerimientos y pasos necesarios para preparar el entorno de desarrollo, obtener el proyecto y comenzar a trabajar con VetCare.

---

# 🛠️ Requerimientos

Antes de comenzar, es necesario contar con los siguientes programas y herramientas:

## 1. 💻 Visual Studio Code

Se requiere tener instalado **Visual Studio Code (VS Code)**, ya que será el entorno de desarrollo utilizado para trabajar en el proyecto.

Se recomienda utilizar una versión actualizada de Visual Studio Code.

### 🐙 Cuenta de GitHub

También es necesario contar con una cuenta de **GitHub**, ya que el proyecto utiliza GitHub para almacenar el código y facilitar el trabajo colaborativo.

Si aún no tienes una cuenta, deberás crear una antes de continuar.

Una vez creada, **inicia sesión en Visual Studio Code con la misma cuenta de GitHub** que utilizarás para trabajar en el proyecto.

> 💡 **Importante:** Utiliza la misma cuenta de GitHub tanto para iniciar sesión en Visual Studio Code como para acceder al repositorio de VetCare.

---

## 2. ☕ Java JDK 21

VetCare está configurado para trabajar con **Java 21**, por lo que es necesario instalar el **JDK 21**.

## 3. 🧩 Extensión de Java para Visual Studio Code

Además de tener **Visual Studio Code** instalado, necesitarás una extensión que nos permitirá trabajar correctamente con Java.

La extensión que debes instalar se llama:

> ☕ **Extension Pack for Java**

### 🚀 ¿No sabes cómo instalarla? ¡No te preocupes!

Es muy fácil. Solo sigue estos pasos:

1. 🧩 Abre **Visual Studio Code**.
2. 🔍 En el menú lateral izquierdo, selecciona **Extensions** (icono de bloques).
3. ⌨️ En el buscador escribe **Extension Pack for Java**.
4. ☕ Selecciona la extensión de **Microsoft**.
5. 📥 Haz clic en **Install**.
6. ✅ ¡Listo! Ya tienes las herramientas necesarias para trabajar con Java en VetCare.

> 💡 **Consejo:** Asegúrate de instalar la extensión oficial de **Microsoft** llamada **Extension Pack for Java**.
