🐾 **VETCARE: Sistema Integral de Gestión y Control Veterinario** 🏥

📚 **Materia:** Programación Orientada a Objetos 1 (POO 1)
🚀 **Tecnologías:** Java (100%) ☕ | Visual Studio Code 💻 | Supabase (PostgreSQL) 🐘 | GitHub 🐙

---

### 🌟 1. Visión del Proyecto

¡El caos de los datos dispersos es cosa del pasado! 🚫 **VetCare** nace como una solución de software súper dinámica diseñada para centralizar, automatizar y sincronizar absolutamente todo el entorno de un centro veterinario. 🐕🐈

Nuestra plataforma unifica los procesos administrativos, médicos y comerciales en un solo lugar. ¡Todo fluye de manera ágil, segura y 100% orientada a objetos! ✨

---

### 🏗️ 2. Arquitectura & Stack Tecnológico

Desarrollamos VetCare con un enfoque moderno, colaborativo y muy técnico, aplicando todos los superpoderes de la POO (abstracción, encapsulamiento, herencia y polimorfismo):

* ☕ **Java (100% Core):** El corazón de nuestro sistema. Un modelo fuertemente tipado para manejar clientes, mascotas y transacciones sin fallas.
* ☁️ **Supabase (PostgreSQL):** Base de datos remota para guardar todo en tiempo real, garantizando que la información esté segura y sincronizada en la nube.
* 🤝 **VS Code & GitHub:** Nuestro entorno de trabajo ideal. Programación ágil y control de versiones distribuido para que el código del equipo se integre a la perfección.

---

### 🎯 3. Alcance del Control Operativo

¡VetCare domina toda la operación de la clínica! 🏢

1. 🩺 **Atención Médica:** Control de consultas, vacunación, desparasitación y procedimientos de salud.
2. ✂️ **Estética y Grooming:** Liquidación automática de baños y cortes con recargos dinámicos según el tamaño y pelaje de los peludos.
3. 🛒 **Módulo Comercial:** Inventario completo y venta de alimentos, medicinas, ropita, accesorios e higiene.
4. 💳 **Cierre de Caja:** Facturación al detalle con múltiples métodos de pago (Efectivo, Nequi, Daviplata, Tarjeta). ¡Todo cuadra! 💰
